# מערכת לניהול תלמידים ומטלות

פתרון מלא למשימת הבית: מערכת אינטרנטית למורים לניהול תלמידים, מטלות וציונים.

## טכנולוגיות שנבחרו

- **Front-end:** HTML5, CSS3 ו-Vanilla JavaScript
- **Back-end:** Node.js עם HTTP server
- **Database:** SQLite באמצעות המודול המובנה `node:sqlite`

נבחרו טכנולוגיות פשוטות וקלות להרצה, ללא צורך ב-frameworks או בספריות חיצוניות.
בצד הלקוח נעשה שימוש ב-Vanilla JavaScript כדי לנהל את הממשק, לבצע קריאות ל-API ולעדכן את התצוגה.
Node.js משמש כשרת שמטפל בבקשות מה-client, מבצע ולידציה ומתקשר עם בסיס הנתונים.
SQLite נבחר משום שהוא בסיס נתונים קל ופשוט, שאינו דורש שרת נפרד ומתאים לפרויקט קטן מסוג זה.

הפרויקט אינו דורש התקנת ספריות npm חיצוניות.

## דרישות מוקדמות
- Node.js **22.5 ומעלה**

## הוראות הפעלה
1. פתחו Terminal בתיקיית הפרויקט.
2. הפעילו:
   npm start

   או ישירות:
   node server.js

3. פתחו בדפדפן:
   http://localhost:3000
